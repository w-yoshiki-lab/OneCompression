NVIDIA L4上で、同じQwen3-8Bに過去の基本・複雑・哲学の15問を実行しました。
各モデルは別々にロードし、greedy decoding、thinking無効で測定しています。

| 項目 | 値 |
| --- | --- |
| GPU | NVIDIA L4 |
| PyTorch | `2.13.0+cu130` |
| BF16モデル | `Qwen/Qwen3-8B` |
| GPTQモデル | 4-bit、group size 128、MSE・actorder有効 |
| 基本質問 | 最大48トークン |
