## 質問 3

**質問**: Pythonで、辞書のリストから顧客ごとの購入合計を返す関数を書いてください。各要素はcustomer_idとamountを持ち、空リストでは空の辞書を返し、amountが負ならValueErrorを送出してください。型ヒントと使用例を含め、コードだけを25行以内で出力してください。

**生成時間**: 10.32秒

**出力**:

````text
```python
from typing import List, Dict

def total_purchases(transactions: List[Dict[str, int]]) -> Dict[int, int]:
    if not transactions:
        return {}
    total: Dict[int, int] = {}
    for t in transactions:
        if t['amount'] < 0:
            raise ValueError("Amount cannot be negative")
        total[t['customer_id']] = total.get(t['customer_id'], 0) + t['amount']
    return total

# 使用例
print(total_purchases([{'customer_id': 1, 'amount': 100}, {'customer_id': 2, 'amount': 50}]))  # {1: 100, 2: 50}
```
````
