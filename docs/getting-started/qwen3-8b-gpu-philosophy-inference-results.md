**出力**:

````text
**具体例：**

**功利主義の判断：**
````

**生成時間**: 13.87秒

**出力**:

````text
『人生に客観的な意味はない』という見解は、実存主義の立場では虚無主義とは必ずしも直結しないとされる。実存主義者は、人生に客観的な意味が存在しないことを前提としつつ、**人間が自ら意味を創造する責任**があると考える。つまり、意味は「与えられる」のではなく、「作り出される」ものであり、その創造が人間の自由と責任の本質である。この視点からすれば、意味の不在はむしろ人間の自由を強調するものであり、虚無主義のように「意味がない」として動機を失うのではなく、**自らの選択と責任を通じて意味を生み出す**ことが可能である。したがって、実存主義的視点では、意味の不在は虚無主義に至る道ではなく、**人間の主体性を高める出発点**とされる。
````
